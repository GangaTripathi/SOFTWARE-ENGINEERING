# 📚 Library Management System

## Software Engineering Lab Assignments

This repository contains the Software Engineering lab assignments based on the **Library Management System (LMS)**. The project demonstrates the application of software engineering concepts, requirement analysis, UML diagrams, and system modelling.

## 🎯 Project Objective

The objective of this project is to design and document a Library Management System that simplifies library operations such as book management, searching, issuing, returning, fine calculation, and user management.

## 🛠️ System Actors

The system consists of the following actors:

- **Student:** Can log in, search for books, issue books, return books, and view borrowing history.
- **Librarian:** Can manage book transactions, approve book issues, process returns, and manage library records.
- **Admin:** Can manage users, maintain book records, and generate reports.

## 📂 Lab Assignments

| Lab No. | Assignment | Description |
|---|---|---|
| LAB 1 | Software Requirements Specification (SRS) | Prepared an SRS document following IEEE recommended standards. |
| LAB 2 | Use Case Diagram | Identified system actors, use cases, preconditions, postconditions, and functions. |
| LAB 3 | Class Diagram | Identified strong and weak classes and designed the UML class diagram. |
| LAB 4 | Activity Diagram | Represented the workflow of the Library Management System. |
| LAB 5 | Data Flow Diagram (DFD) | Designed Level 0 and Level 1 Data Flow Diagrams. |
| LAB 6 | Sequence Diagram | Represented interactions between system actors and components over time. |

## ⚙️ Main Features of the Proposed System

- User registration and login
- Book searching and availability checking
- Book issue and return management
- Due date management
- Fine calculation for overdue books
- User and book record management
- Library report generation
